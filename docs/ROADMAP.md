# Roadmapa Codex Agent Platform

| Milník | Rozsah |
|---|---|
| V1.0 | Stávající lokální tým Codex, ověřování, audit, izolované scénáře, baseline a kontrola před vydáním. |
| V1.1 | Kanálový kontrakt a adaptér Slack se schvalováním a kontraktními testy. |
| V1.2 | Adaptér Teams se stejným kontraktem, identitou a řízením oprávnění. |
| V2.0 | Firemní instalace, oddělení zákazníků, migrace, návrat, sledování a postupné aktualizace. |

Podrobnosti a akceptační podmínky jsou v [architektonické roadmapě](Codex_Agent_Platform_architektura_roadmap_a_zadani_pro_Codex.docx). Testování jádra používá místní šablonu zadání a výstupu. Samostatné rozhraní pro vstupní kanály vznikne s prvním adaptérem.
